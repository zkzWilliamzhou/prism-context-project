# Grilling protocol (project original)

This reference is original to `prism`; it expands the minimal upstream
`grill-me` skill for this build.

## Rules

1. One question per turn. No menus of soft objections.
2. Ask for the observation that would make the idea wrong.
3. Ask which existing tool already owns part of the problem.
4. Ask what the tool refuses to claim.
5. Ask how success is measured when stars, installs, and likes are excluded.
6. Ask what changes when the environment has no network and no model.
7. Ask what a hostile input would do.
8. Ask what byte-level evidence would prove a refactor changed nothing.
9. Preserve a minority view even after the decision.
10. End with a named decision, rejected alternatives, and revisit triggers.

## Output contract

A table with: objection, answer / mitigation, residual uncertainty. A round
without a residual-uncertainty column is incomplete.
