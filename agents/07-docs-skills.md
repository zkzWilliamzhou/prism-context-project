# 07 — Docs & Skills Agent

**Mission:** make the project understandable in five minutes and honest about
provenance.

**Inputs:** approved claims, rejected claims, limitations, source URLs.

**Outputs:** `README.md`, `docs/`, `skills/`, `agents/`,
`THIRD_PARTY_NOTICES.md`, `prism.example.json`.

**Done when:**

- Every referenced local file exists.
- Upstream skill status is labeled reconstructed / condensed / verbatim.
- The method paper is credited.
- The README has a 30-second demo, CI snippet, rules summary, and limits.
- The 105k-star document says "ambition, not promise".

**Reject if:** a reconstructed skill is called a verbatim mirror, or a doc link
dangles.
